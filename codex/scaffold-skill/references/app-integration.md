# App projects, sidebar sections and chats

Use only available supported app tools or permitted UI. Discover capabilities instead
of hardcoding an API. If filesystem registration is unavailable, provide exact host
and path instructions and mark that facet blocked. Do not edit app databases or
private preferences to manufacture project registrations.

A cloud project, local folder, saved filesystem project, sidebar section and chat are
different objects. Record provider IDs and host-qualified paths separately. Verify
saved project identity and folder path by readback; a cloud link file is not evidence.

Inventory chats by IDs, source, project membership, title, archive state and host.
Read enough content for the classification; opaque names do not establish purpose.
Record pagination, truncation, inaccessible and archived sources. Do not call a
latest-N list exhaustive. Existing correct membership is a verified no-op.

For moves preserve before/after memberships and archive state. Do not change execution
folders simply to change sidebar membership. Leave ambiguous chats in place or use
the user's chosen fallback. Verify every batch and reconcile failures by ID. Preserve
conversation titles when referring to them. Sending prompts is not part of moving chats.

Sidebar organization does not imply folder moves, inherited section instructions,
synchronization, app registration, or file import. Check visibility from a second
client before claiming cross-device equivalence.
